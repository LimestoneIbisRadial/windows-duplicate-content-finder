## 🛠️ Troubleshooting

- Ensure the downloaded archive is named exactly **`WindowsDuplicateContentFinder.zip`**.
- Extract it before running **`WindowsDuplicateContentFinder.exe`**.

- Too many results: narrow the folders or matching criteria.
- The scan is slow: reduce scope and exclude irrelevant large folders.
- A file cannot be removed: check permissions or whether another program is using it.
- **Download returns 404:** The release has not yet been published or its asset is not named `WindowsDuplicateContentFinder.zip`.
